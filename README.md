# WheatBot

WheatBot is a Discord bot designed for the Diamond Fire game server.  
It provides game-related information with the commands "/trinkets" and "/gow"

---

## Installation

### Requirements:
- Python
- discord.py (```pip install discord```)

### 1. Clone the repository

```bash
git clone https://github.com/OMBRE77/WheatBot.git
cd WheatBot
```

### 2. Setup the bot

Enter your bot token in **.token**  
Enter your server id in **.server_id**

### 3. Lauch
Open a terminal in the **WheatBot** folder then type ```bash python .``` and let the file running.

 ---

## Features

- " **/gow [level]** " get the price and the buff of a specific **Gift of Wheat** level
- " **/trinkets [count]** " get the price of a certain amount of **trinkets**
